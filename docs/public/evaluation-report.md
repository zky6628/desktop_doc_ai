# AI知识工作台评测报告

本报告整理已有的 2026-09-23 基线评测及 2026-09-27 关键词检索改版评测。

## 样本与方法

评测使用 5 份文档、115 道问题，覆盖制度、票务与目录类内容；不同配置使用同一语料和问题集。原始文档、提问、答案、引用和运行标识不随本报告发布。

环境为 Windows 本机客户端与 FastAPI 服务。模型配置记录为 qwen3.7-text-embedding（1024 维）、qwen3-rerank（top\_n=5）、qwen3.8-max（关闭思考模式）。这些名称来自当时的项目记录，不表示当前供应商可用性。

问题按服务端串行执行。文档相关性采用自动规则与内容证据复核，并非独立人工逐题标注；nDCG 在缺少分级标注时使用二元相关性。切片相关性取自回答引用快照，被引父切片按其子切片是否召回判定，因此不能视为独立人工真值。

## 汇总结果

| 指标                |      基线 |           关键词改版后 |
| ----------------- | ------: | ---------------: |
| 完成问题              | 115/115 |          115/115 |
| 文档 Recall\@5      |   1.000 |            1.000 |
| 文档 MRR\@10        |  0.9174 |           0.9174 |
| 文档 nDCG\@10       |  0.9390 |           0.9390 |
| 检索耗时 P95          |    16ms |             16ms |
| 重排耗时 P95          |   219ms |            235ms |
| 服务端首 token 时间 P95 |  1460ms |           1551ms |
| 关键词排名非空候选比例       |  0/2300 | 1808/2300（78.6%） |

改版后切片召回@5 为 0.9901，切片召回@20 为 1.000。关键词路开始稳定参与候选排序，文档级指标保持不变。

检索 16ms 是分段耗时，不是端到端回答时间；评测启用了查询嵌入缓存与连接预热，不能当作冷启动或无缓存性能。服务端首 token 时间也不包含客户端点击到首帧渲染的完整过程，客户端口径当时尚未完成重跑。

## 固定候选池对照

| 指标          |  关键词参与 | 无关键词近似 |         差值 |
| ----------- | -----: | -----: | ---------: |
| 切片召回@5      | 0.9901 | 0.9858 | +0.43 个百分点 |
| 文档 MRR\@10  | 0.9174 | 0.9043 | +1.31 个百分点 |
| 文档 nDCG\@10 | 0.9390 | 0.9294 | +0.96 个百分点 |

无关键词一侧是在已固定的融合候选池内按向量名次重排的近似结果，并未关闭关键词路重新独立召回。该对照只能说明当前候选池内的排序与前五覆盖变化，不能证明关键词路补回了池外内容。

## 拒答与局限

基线另有 20 道拒答测试，19 道回答表达资料未覆盖；属于话术级拒答，不是检索为空触发的结构化拒答。失败案例是把一个地区的票务问题回答成另一个地区的规则，暴露跨主体混淆。关键词改版后没有重跑此测试，不能把 95% 作为新版本拒答结果。

样本规模较小且文档级 Recall\@5 已饱和，满分不等于通用回答准确率。19 道排序弱点集中在近似主题文档，仍可能混有标注问题，尚未全部人工确认。原始报告部分早期表述与后来补充的切片对照不一致，公开版分别呈现“文档级指标未变”和“固定候选池排序改善”，不将其合并为独立召回收益。

本报告展示特定条件下的结果，不提供通用准确率、全链路低延迟或逐句事实正确的保证。
